# LOCKED IN V2 Vault

This is a standalone AI-oriented project brain for LOCKED IN V2.

It is intentionally:
- simple;
- plugin-independent;
- Markdown-first;
- portable;
- suitable for later copying into a larger Obsidian second-brain vault.

Start with `PROJECT.md`.

## Later merge into a larger vault

Copy this whole project directory into a location such as:

`Projects/LOCKED IN V2/`

Because the project uses internal files, relative links and local assets, it should remain self-contained.

Do not rely on this vault's `.obsidian` folder as part of project truth.
