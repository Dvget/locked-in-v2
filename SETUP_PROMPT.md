# Setup prompt for an AI coding/file agent

Create a new standalone Obsidian vault/project directory named `LOCKED IN V2`.

Use the file tree and contents from this starter package exactly as the initial project brain.

Rules:
- Do not add plugins.
- Do not create dashboards, Bases, Canvas files, templates or automation systems.
- Keep all project truth in plain Markdown.
- Keep images/assets inside the project directory.
- Do not modify the legacy LOCKED IN repo or old Obsidian workspace.
- If this directory is version-controlled, commit the initial vault as a clean baseline.
- Ensure `PROJECT.md`, `STATUS.md`, `DECISIONS.md`, `INDEX.md`, `CLAUDE.md` and `AGENTS.md` are at the project root.
- Future agents should read `PROJECT.md` first.
- The project must remain portable so the whole directory can later be copied into a larger Obsidian vault without restructuring.
