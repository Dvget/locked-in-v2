# Legacy → V2 Map

Compact map from the legacy SwiftUI app to V2 (React Native / Expo). Not a spec. V2 decisions in [DECISIONS.md](../DECISIONS.md) override legacy behavior.

Source: `Dvget/locked-in`, branch `codex/locked-in-0.8.8`, **0.8.8 Build 60** (read-only; analyzed via a scratch clone outside this repo). Legacy paths below are relative to `LockedIn/`. Behavioral truth for legacy: `PROJECT_STATE.md`, issues #19 (Running), #31 (Weekly Report), #36 (migration).

Status values: **übernehmen** · **übernehmen + verbessern** · **neu bauen** · **verwerfen**

## Legacy stack facts that shape the port

- SwiftUI + SwiftData (`WorkoutRecord`, `SetRecord`, `RunRecord`, `RunTrackPoint`, `StepRecord`, `WeightRecord`), local store, no CloudKit.
- Training plans are **not** in SwiftData: JSON file `training-plans.json` (`TrainingPlans.swift`), plan history snapshots 30 days.
- Tracking data and plan configuration are deliberately separate; restoring plans must never overwrite tracking data (legacy non-regression rule, keep).
- 171 Swift package tests exist in `LockedInTests/` (Build55–60 tests, Dashboard/Weekly/Analytics). Use them as behavior oracles when porting logic.
- Week = Monday-first (`firstWeekday = 2`), German UI strings.

## Future-only (no build now)

- **Route map in Running mode (D-044), Strava-style:** possible later, live and/or post-run. Only the option is kept open: raw GPS track points per run (lat/lon/timestamp/accuracy, accepted/rejected flag) stored separately from derived metrics, so a route can be drawn later without re-recording. No map UI, no map library, no commitment that it ever ships. Choice of map technology is deferred (any map SDK is native code and would need a Dev Client rebuild). Legacy has no route map to port.

## Open items surfaced by the analysis

- Weekly Report: auto-open once per new week (legacy) vs. Dashboard entry only (V2 today).
- Dashboard detail screens (legacy) vs. Dashboard + Progress only.

- BLE scale import (legacy feature not mentioned in V2 docs).
- Native capabilities from [ARCHITECTURE.md](../30_Technical/ARCHITECTURE.md) remain unproven and gate Running/Live Activity/Steps porting.
