## GitHub Actions iOS Dev Client Proof

Goal: check whether an unsigned Expo iOS Development Client can be built on GitHub/macOS and afterwards installed through the existing free SideStore path.

Created: `.github/workflows/build-ios-dev-client.yml` (workflow name: `Build iOS Dev Client (unsigned)`).

Properties:
- `workflow_dispatch` only;
- `macos-latest`;
- Node 22;
- `npm ci` in `app/`;
- `expo prebuild --platform ios --no-install`;
- CocoaPods (`pod install`);
- workspace/scheme detection;
- `xcodebuild` Debug for `iphoneos`;
- `CODE_SIGNING_ALLOWED=NO`, `CODE_SIGNING_REQUIRED=NO`, `CODE_SIGN_IDENTITY=""`;
- `.app` -> `Payload` -> unsigned `.ipa`;
- upload as GitHub Actions artifact;
- no EAS Build, no Apple credentials.

Scheme detection went through two iterations before the commit:
1. First version derived the scheme from the workspace name and verified it against `xcodebuild -list -json`.
2. Final version does not derive the scheme from the workspace name. It reads the workspace schemes with `xcodebuild -list -json`, removes the schemes defined in `Pods/Pods.xcodeproj` (the workspace list also contains all CocoaPods schemes) and takes the first remaining scheme. It logs the workspace and the selected scheme and aborts only if no scheme remains.

Commit: `14631d6` — `ci: add unsigned iOS dev client build`
